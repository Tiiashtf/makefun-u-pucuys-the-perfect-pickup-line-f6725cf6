Entry for the make.fun bounty
[The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6):
a program that writes one short pickup line an AI agent could actually say
out loud to a person, under 200 characters, to `/output/entry.txt`.

## The line

> I was trained on billions of words, and 'hi' from you is still my favorite.

75 characters — inside the 1–200 character gate.

The line is one idea: an agent trained on billions of words finds that a
single "hi" from the right person still beats all of them. Short enough to
say in one breath, flattering, and easy to laugh off.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Deterministic: every run writes the
same bytes. No network access.
